# 미제작 어종 작업 순서와 통과 기준

기준일: 2026-11-08. 현재 게임에 등장하는 물고기와 제작 후보를 분리한다.

## 이번 작업

- 기존 배치 002에서 `NOT_GENERATED`로 남아 있던 가시가오리 (*Raja clavata*), 미거 (*Argyrosomus regius*)의 독립 원화를 제작했다.
- 두 종 모두 초안 및 1회 수정본을 생성했으나, 최종 수정본에 붉은/노란 외곽 잔색과 가장자리 알파 잡티가 남아 안전 여백 검사에 실패했다. 추가 수정·재검수 전에는 게임용으로 사용할 수 없다.
- 상태는 `ART_REVIEW`다. 게임 ID 할당·도감 수 증가·LIVE 전환은 아직 하지 않는다.
- 원본 후보 목록의 상태는 오래된 값이므로 그대로 믿지 않는다. 배치별 제작 기록, 실제 파일, 설치 manifest와 교차 확인한다.
- 1,539개 과학명 후보 중 기존 제작 기록 및 이번 작업과 매칭된 것은 31개, 나머지는 1,508개다. **1,508개가 모두 신규 고유종이거나 그림이 전혀 없다는 뜻은 아니다.** 기존 통칭과의 학명 매핑 및 과거 생성 이미지 확인이 더 필요하다.
- 이전 1차 11종과 2·3차 10종은 제작 기록상 이미지가 있으므로 새로 그리는 대상에서 제외하고, 기존 이미지 확보·검수·설치 작업으로 따로 처리한다.

## 진행 순서

| 순서 | 작업 단위 | 끝나는 조건 |
| --- | --- | --- |
| 1 | 이번 미제작 2종 | 개별 원화 생성 및 문제점 기록. 승인 전 ART_REVIEW 유지 |
| 2 | 다음 24종 후보 사전 검증 | 학명·기존 그림·실제 서식·성어 크기 확인. 부적합 후보는 보류 |
| 3 | 검증 통과한 6종 | 한 호출에 한 종씩 개별 투명 PNG 제작 |
| 4 | 같은 6종 품질 검수 | 실루엣·해부학·알파·게임 축소 가독성 확인, 실패한 개체만 수정 |
| 5 | 승인된 6종 설치 | ID·지역·크기·희귀도·행동 연결, QA·배포·서비스 해시 확인 |
| 6 | 다음 묶음 | 앞 묶음의 기록을 갱신한 뒤 진행. 세션 종료 후 자동 작업을 약속하지 않음 |

6종은 작업 권장량이며 실패한 그림을 채우려고 품질 기준을 낮추지 않는다. 먼저 통과한 소수만 설치해도 된다.

## 지역·크기 배정 원칙

- `fish-art-next-work-queue.json`은 **제작 승인 목록이 아니라 사전 검증 순서**다. 원본의 proposedStage/proposedSizeClass는 그대로 보존한 미검증 값이며, 실제 분포나 성어 크기의 근거로 쓰지 않는다.
- 현재는 12개 임시 지역별로 2개씩, 총 24개의 확인 대상을 뽑았다. 서로 다른 과와 크기 제안을 우선했지만, 잘못된 지역·크기 값은 출처 확인 후 수정해야 한다.
- 실제 제작 묶음은 검증된 후보 중 소형 2·중형 2·대형 2를 목표로 한다. 가능하면 3개 이상 지역과 서로 다른 체형을 포함한다.
- 지역의 부족 수량을 채우려고 실제 서식과 맞지 않는 어종을 옮기지 않는다. 적합한 후보가 부족하면 별도 조사 대기 상태로 남긴다.
- 가오리·넙치처럼 납작한 종류는 체형이 보이면서도 실제 횡스크롤 카메라와 맞는 각도를 별도 검수한다. 평범한 물고기의 색만 바꾸는 방식은 금지한다.

## 생성 전 필수 확인

1. 유효 학명·동의어·한글 통칭을 확인하고 기존 304개 ID 및 승인/대기 원화와 비교한다.
2. 기존 물고기와 다른 **비색상 형태 특징 2개 이상**을 기록한다. 예: 턱 비율, 등지느러미 위치, 꼬리 형태, 체고, 가시 구조. 차이를 설명할 수 없으면 보류한다.
3. 실제 서식 환경과 성어 크기 출처를 적고, 게임 지역 및 크기값을 확정한다. 희귀도는 생물학적 희귀성과 별개의 게임 밸런스 값이다.
4. 한 종 한 파일, 오른쪽 전신, 원본 고해상도, 투명 RGBA, 전체 지느러미와 꼬리, 넉넉한 여백을 명시한다. 포스터·시트·카드 UI는 생성하지 않는다.

## 생성 후 통과 기준

- 파일 무결성: PNG 실제 디코딩 성공, RGBA 및 투명 영역 확인, 원본 크기와 SHA-256 기록. 무단 확대 금지.
- 경계: 모든 신체가 화면 안에 있고, 긴 꼬리·수염·지느러미까지 안전 여백 확보. 검정/흰색/게임 배경에서 붉은색·노란색·흰색 잔색과 핀홀 확인.
- 형태: 손발처럼 보이는 지느러미, 중복 눈, 잘못된 꼬리·등지느러미 수, 부자연스러운 원근을 확인한다.
- 중복: 원본 해시 일치 외에 검정 실루엣과 실제 게임 크기의 모습도 비교한다. 동일 체형에 색·무늬만 다른 결과는 보류한다.
- 연결: 도감·낚시·획득 결과·아쿠아리움에 동일 승인 PNG를 사용한다. 약점·입·회전축을 이미지에 맞춰 잡는다.
- 행동: 속도만 바꾸지 않고 유영·회전·도주·정지·군집·수심 중 최소 2개 이상 차이를 준다.
- 설치: [업로드·배포 기준](tools/UPLOAD_DEPLOY_GUIDE.md)에 따라 원본 blob 해시, QA, Pages 및 서비스 PNG를 검증한다.

## 상태와 기록

`PREFLIGHT_REQUIRED → ART_REVIEW → APPROVED_ASSET → LIVE`

각 상태에는 근거가 필요하다. 이미지 파일이 없는 후보에는 gameId를 미리 추가하지 않는다. 생성되었으나 검수 전인 그림을 LIVE로 세지 않는다.

- 다음 후보 순서: [fish-art-next-work-queue.json](fish-art-next-work-queue.json)
- 순서 재생성: `python3 human-fishing/scripts/build_fish_art_work_queue.py`
- 생성 프롬프트·현재 검토 기록: `art-review/batch-005/`
- 같은 학명의 기존 그림을 먼저 검색하고, 발견되면 재생성 대신 검수/설치 대기로 옮긴다.

## 이번 2종의 참고 자료

- 미거의 큰 머리·긴 몸·작은 눈·긴 두 번째 등지느러미·은회색/청동색 체색은 [FAO 종 설명](https://www.fao.org/fishery/docs/CDrom/aquaculture/I1129m/file/en/en_meagre.htm)을 참고했다.
- 가시가오리의 원반·등 가시·꼬리 띠와 저서 환경은 [CIESM 종 설명](https://ciesm.org/marine/programs/skatesandrays/raja-clavata/)을 참고했다.
- 생성 이미지는 게임용 해석이며 과학 도판으로 인증된 자료가 아니다. 위 자료는 검토 근거이고 이미지를 그대로 복사한 것이 아니다.
