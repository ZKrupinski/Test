# 인간낚시 도감 원본 이미지 및 중복 정리 기록

검증일: 2026-11-08 (KST) · 저장소: ZKrupinski/Test / main.

## 실루엣 누락 현상 대응
- 원본 F PNG 356개, 특수생물 S PNG 13개, 합계 369개를 GitHub Actions + Pillow로 읽어 alpha 채널, 내부 픽셀, 실제 이미지 바운딩박스까지 검사했다. 손상 이미지, alpha가 비어 있는 원본은 없었다.
- F305/F307/F308/F309/F310/F313/F317/F318의 원본 파일은 미설치 상태이며, 현재 활성 카탈로그에서도 의도적으로 제외되어 있다. 도감에 존재하지 않는 그림을 등록하지 않는다.
- 도감 미획득 실루엣은 원본 PNG의 알파 형태를 유지하며 순수한 검정색에 얇은 밝은 외곽 그림자를 더해 어두운 청록 배경에서도 구분되게 했다.
- 화면 첫 48개의 이미지는 우선 로딩하고, 나머지는 지연 로딩한다. 이미지 다운로드 실패 시 1회 재시도하고, 재실패하면 비어 있는 칸 대신 오류 문구를 표시한다.
- PNG 원본 바이트, 이름 없는 임시 대체 스프라이트, 기존 완성품 리소스는 변경하지 않았다.

## 산호초 반복 비주얼 정리
실제 PNG 12종을 개별 열람해 아래 항목이 기존 고유 실루엣을 거의 그대로 복제하거나 이름이 다른 물고기 그림으로 잘못 연결되어 있음을 확인했다.

| 숨긴 ID | 원래 이름/문제 | 정규 ID / 기준 원화 |
| --- | --- | --- |
| F122 | 퍼큘라클라운피시: F121과 거의 같은 흰동가리 | F121 흰동가리 |

등록된 별도 개체는 도감과 일반 야생 출현에서 제외했지만, 기존 PNG를 삭제하지 않고 획득 수량과 전시 기록을 기준 ID에 이전한다. 기본 240개 ID의 번호 순서를 유지하므로 기존 서식지 인덱스가 흐트러지지 않는다.

중복 제거 후 기존 원화 등록: **내부 283개, 표시되는 고유 원화 282개**. 별도로 설치된 신화 특수생물 13종과 후속 원본 어종 배치는 유지한다.

검증: `human-fishing/qa-codex-visibility.cjs`, `qa-fish-visual-catalog.cjs`, `qa-special-creatures.cjs`, `qa-smoke.cjs`. 모바일 브라우저에서 실제 스크롤 표시를 최종 사용자 관점으로 확인하는 과정은 별도다.
