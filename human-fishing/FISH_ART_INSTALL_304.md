# 인간낚시 — 304종 비트맵 물고기 리소스 적용 가이드 (2026-11-06)

**게임:** https://zkrupinski.github.io/Test/human-fishing/  
**업로더:** https://zkrupinski.github.io/Test/human-fishing/tools/fish-bitmap-uploader.html

## 현황
- 게임 코드에 원본 도감 ID **F001–F240**의 고해상도 비트맵 로딩과 보너스 변종 **F241–F304** 등록·출현·도감 표시를 연결했습니다.
- 업로드가 완료되기 전에는 기존 게임을 손상시키지 않기 위해 절차적으로 그린 물고기를 유지합니다.
- *정확한 비트맵 적용 완료*는 `assets/fish/ready.js`와 `individual/F001.png`부터 `F304.png`까지 전체 파일이 성공적으로 설치된 뒤에만 성립합니다.
- 사용자 저장키 `humanFishingAlpha01`와 기존 240종의 ID를 변경하지 않습니다.

## 에셋 가져오기
1. 제공된 `fish-art-import.zip` 파일을 내려받습니다. ZIP에는 개별 RGBA PNG **304개**, 전체 이름·희귀도·지역·크기급을 포함한 `manifest.json`, 최종 활성화 스위치 `ready.js`가 있습니다.
2. [GitHub 업로드 화면](https://github.com/ZKrupinski/Test/upload/main/human-fishing)에서 ZIP 한 파일을 `human-fishing/fish-art-import.zip`으로 업로드하여 커밋하거나, 위 물고기 전용 업로더에 GitHub Contents 권한 토큰을 넣고 업로드합니다.
3. [자동 설치 워크플로](https://github.com/ZKrupinski/Test/actions/workflows/install-human-fish-art.yml)가 파일 개수·PNG 형식·투명 채널·고유 ID를 검증한 후 압축을 해제하여 `human-fishing/assets/fish/individual/`에 설치합니다. 완료 커밋이 올라오면 ZIP은 제거됩니다.
4. 게임 링크를 새로 열어 최초 스테이지 그림 로딩이 끝나는지 확인합니다. 해당 지역의 PNG가 준비되어야 화면이 열리고, 이후 다른 지역 선택 시 새 지역의 그림을 불러온 다음 진입합니다.

## 원본 커팅 규칙
- 12장 기본 시트는 각각 4열×5행의 고유 영역을 먼저 고정한 뒤, **각 영역에서 가장 큰 불투명 개체 연결 성분만** 남겼습니다.
- 보너스 그림은 불규칙 배치이므로 **전체 이미지에서 개체별 알파 연결 성분을 분리**했습니다. 사각 격자를 잘라 그대로 렌더링하지 않습니다.
- 각각 투명 PNG로 저장해 다른 물고기 꼬리나 이펙트, 유색 배경 잔여물이 옆 어종에 묻지 않도록 했습니다.
- 그림 크기는 원본 픽셀 범위 내에서 유지했고 업스케일하지 않았습니다. 게임에서는 원본 PNG를 직접 그리면서 크기급만 적용합니다.
- 이미지 중복인 29166.png는 29162.png와 중복되므로 별도로 등록하지 않았습니다.

## 세이브 / 오류 회피
- 기존 240종 ID와 저장 데이터는 유지합니다. 새 등록 항목은 F241부터 시작합니다.
- 누락된 PNG를 포함한 ZIP은 검증에서 실패하므로 **일부만 설치된 비트맵이 활성화되지 않습니다.**
- 블루탱의 전용 동작별 애니메이션은 기존 플레이어가 우선합니다. 해당 어종도 도감에는 비트맵 이미지가 표시됩니다.
