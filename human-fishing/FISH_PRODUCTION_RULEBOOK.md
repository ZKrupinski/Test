# 인간낚시 1,600종 확장 — 영구 제작·검수 규칙
**버전:** 2026-11-08 · **상태:** 프로젝트 잠금 규격 (인간낚시 전용)
**게임:** https://zkrupinski.github.io/Test/human-fishing/

## 변하지 않는 목표
- 기존 독립 수집 항목 **291개**를 보호하며, 최종 **실제 고유 어종 1,600종 이상**을 목표로 한다.
- 숫자를 채우기 위해 색·무늬만 다른 버전, 같은 이미지의 이름 변경, 유어·성어의 무분별한 중복, 동의어·옛 학명만 다른 물고기를 새 종으로 세지 않는다.
- 이미 수집한 기록과 기존 F001–F304의 저장 ID·원본 PNG를 삭제·변경하지 않는다. 기존 중복으로 판단되어 통합된 13개 ID는 별도 종 카운트에 복원하지 않는다. 기존 포획 보유량은 대표 종으로 합산한다.
- 고유 후보와 **그림 완성**, **검수 통과**, **게임 실제 출현·도감 등록**의 네 단계를 절대 혼동하지 않는다.

## 종 목록 / 검증 게이트
1. 검증 가능한 실제 이명식 학명을 기준으로 고유키를 만들고 동의어를 통합한다. 학명만 같으면 이름·희귀도가 달라도 동일 종으로 처리한다.
2. 기본 291종의 한국어 통칭에는 고정된 학명 매핑이 아직 없어, 신규 데이터의 기존 목록 대비 중복검사는 **완결되지 않았다**. 목록의 모든 후보는 기존 304개 PNG와 52개 기존 제작 후보를 대조해야 한다.
3. ASFiS의 'NA'는 그 자료에서 경고 없음일 뿐 전문가 승인이나 최신 분류학적 유효성의 증거가 아니다. 경고 항목은 따로 식별·검증한다.
4. 기존 종과 같은 속(genus)의 후보는 주의 항목. 실제 사진·해부학을 참조해 입·눈·몸통·등/배/가슴지느러미·꼬리 등의 **형태 차이**를 아트로 표현할 수 없으면 보류한다.
5. 생물학적 서식 지역·환경의 출처를 확인한 뒤 12개 낚시터 중 실제 출현 스테이지를 결정한다. 지금의 `proposedStage`는 **검수 전 배치 제안**일 뿐 확정 지리 정보가 아니다.
6. 크기 SMALL/MEDIUM/LARGE는 성어의 실제 스케일을 확인해서 확정한다. 게임 속 등급 COMMON/UNCOMMON/RARE/EPIC/LEGEND/MYTHIC은 생물학적 멸종 위험도를 의미하지 않으며, 포획 난이도·게임 밸런스용이다.

## 이미지 제작 / 품질 게이트
7. 어종마다 **별도** 고해상도 투명 RGBA PNG가 1개 이상 있어야 한다. 서로 다른 종이 같은 PNG나 같은 실루엣에 색상만 바꾼 그림을 공유하지 않도록 한다.
8. 통짜 시트의 사각형만 대충 자르지 않는다. 알파가 깨끗한 개체 단위 마스크로 분리, 외곽 핀홀/흰 테두리/잔색·옆 물고기 혼입·꼬리/지느러미 잘림을 검사한다. 원본 픽셀을 보존하고 강제 업스케일 금지.
9. 신규 그림 전체와 기존 304개 원본 그림의 시각적 중복을 비교한다. 픽셀 해시뿐 아니라 실루엣/형태 근접 중복을 별도 시각 검수한다. 같은 계열 종은 **실제 지느러미 수·비율·머리·입·꼬리 구조의 차이**를 명시한다.
10. 작업 시트는 검수 프리뷰용이다. 완성으로 보고하거나 게임에 반영하기 전 반드시 개별 PNG로 분리하고 해당 후보와 1:1 연결한다.
11. 희귀도·색상·이름을 바꿔 같은 이미지를 재사용하지 않는다. 신규 어종의 도감/실제 낚시/포획 결과/아쿠아리움은 **동일한 승인 PNG** 사용.
12. 새 이미지가 없는 후보는 대체 그림으로 도감 수량만 늘리지 않는다. 유효한 실제 리소스, 알파, 메타데이터, 행동 QA 통과 시에만 F305 이후 신규 고정 게임 ID를 할당한다.

## 행동 / 생태 / UI 게이트
13. 크기와 속도만 바꾸는 클론 AI 금지. 28가지 행동 원형(빠른 돌진, 바닥 잠복, 떼 유지/분산, 순찰, 위기 회피, 직선 질주, 유영 상승, 관성 회전 등)에 종별 속도·경계반경·회전성·도주 폭발·서식 깊이의 차등값을 조합한다. 행동은 실제 생태와 맞는지 확인한 뒤 확정한다.
14. 몸 길이·가시·지느러미·꼬리 등 외형 차이가 게임 화면에서도 드러나게 한다. 희귀/대형일수록 실제로 포획 난이도가 높고 움직임이 다르게 느껴지도록 검수한다.
15. 지역별 생태계 유입/이탈, 군집과 단독 행동, 수심, 포획·피버·도감 썸네일을 게임 안에서 함께 테스트한다. 미발견 종은 검은 실루엣만 보여준다.
16. 데이터 ID/저장 마이그레이션은 항상 역호환·중복 실행 무해(idempotent). 16:9 모바일 가로모드/원본 UI/전체 프리로드 규칙을 훼손하지 않는다. 배포는 GitHub Pages/기존 업로더를 이용하며 Cloudflare 사용 금지.

## 제작 기준 / 상태 정의
- `CANDIDATE`: 학명만 확인한 제작 기획안. 도감·실제 출현·수집 수량에 더하지 않는다.
- `ART_REVIEW`: 서로 다른 실루엣 원화를 생산/검토 중. 수량에 더하지 않는다.
- `APPROVED_ASSET`: 1:1 PNG와 종·지역·크기·AI 메타 검수됨. 단 실제 게임 배포 이전이므로 수량에 더하지 않는다.
- `LIVE`: PNG·출현·수집·도감·아쿠아리움·저장 테스트 통과, GitHub 배포 완료. 이때에만 실제 어종 수로 센다.

## 지역·원화 배치 보강 (2026-11-08)
- 신규 후보 최소 80개를 12개 지역별로 확보하는 보강 목표를 둔다. 기존 소스가 과소표집한 심해·한대·담수는 `fish-habitat-sourcing-gaps.json`에 수량을 기록한다.
- 분포를 억지로 맞추기 위해 온대/연안 종을 극지·심해로 임의 이동하지 않는다. 실제 서식 근거 있는 신규 후보를 별도 수집한다.
- 첫 독립 PNG 제작 대상 12종과 실제 원화 생성 요청 4건은 `fish-art-batch-001.json`에 보존하며, 생성 요청을 검수·도감 반영 완료로 표현하지 않는다.

## 비어류 및 창작 수중 생물 허용 (2026-11-08)
- 물고기 1,600종 목표는 유지한다. 두족류·갑각류·유즐동물·해파리류와 **실재하지 않는 창작 수중 생물**은 별도의 `S###` 특수 생물 도감으로 추가할 수 있다.
- 실제 생물은 확인된 학명을 기록한다. 뱀파이어오징어는 실제 두족류 *Vampyroteuthis infernalis*다. 창작 생물은 학명이 없어도 허용하되 `origin=ORIGINAL_FICTIONAL`을 반드시 표시한다.
- 실재 종과 창작종을 구분하고, 물고기 1,600종 집계에 비어류를 합산하지 않는다. 이미지·이름·희귀도만 변경한 중복은 모두 금지한다.
- `S001`은 실제 투명 PNG가 설치되고 검증된 경우에만 심해 스테이지·도감에 활성화한다. 기존 291개 물고기의 ID·보유량·저장은 보호한다.
- 비어류도 고유 고해상도 RGBA, 겹침 없는 실루엣, 몸 크기, 희귀도, 독립된 이동·회피 패턴, 도감·포획 결과·아쿠아리움에서 동일 이미지 사용 원칙을 적용한다.
- 이전에 생성한 뱀파이어오징어 그림은 창작적·반실사 연출이 강하므로 과학 도판으로 간주하지 않는다. 실제 뱀파이어오징어의 행동은 느린 부유, 외투막 뒤집기 및 청색 발광 회피를 참고한다.
