# 어종 원화 우선 적용 · 2026-11-08

이미 만든 원화의 **실제 사용 가능 여부**를 앞에 두는 작업표. 이 문서는 Live/Ready/Review를 분리합니다.

- 현재 GitHub 게임의 활성 물고기 **304종**(기존 291 + 4차 5 + Work 8).
- Library ZIP에서 실제 바이트와 PNG RGBA/알파를 확인한 **16종**: 1차 F306·F311·F312·F314·F315·F316, 2·3차 F319–F328.
- 특수 생물 **S001 뱀파이어오징어** 1종은 별도 원본과 원본 SHA-256이 준비됐으나 미설치. 게임 어류 1,600종 목표와 별도.
- 1차 F305/F308/F309/F313/F317 **5종**은 배경 투명 알파가 이미지 경계에 닿아 잘림 위험이 있어 검수 대기. F307/F310/F318 **3종**은 기존 형태·해부학 검수 대기.
- 2차 큐에 남아 있던 가시가오리/미거는 이미 Work 원본 F334/F335에 배정됐으므로 중복 제작 큐에서 해소했고, 원본 가장자리 문제는 계속 경고.
- 추가 단독 원화와 시트는 [통합 원화 인벤토리](fish-art-fast-inventory.json)에 원본명·기존 어종/대체 검수 상태로 기록. 52개 아트 후보는 중복·알파 커팅 검수 전에는 도감 수에 넣지 않음.
- 특수 생물 별도 후보는 [24종 기획](special-creature-candidates.json)에 반영. S001만 원본 존재, 나머지 23종은 기획 상태(그림 제작 완료 아님).

원본 PNG는 수정 없이 패키지 `fish-art-fast-pack-17.zip`에 모았습니다. 이 ZIP을 [통합 업로더](tools/fish-bitmap-uploader.html)에 한 번 올리면 새 통합 설치 Workflow가 16+1 원본을 함께 검증해 등록합니다. **ZIP을 사용자가 업로드하기 전에는 LIVE가 아닙니다.**

설치 성공 시 물고기 **320종**, 특수 생물 **1종**, 포획 총 **321종**으로 증가합니다. GitHub Actions 게임 QA와 Pages 배포 확인 후 최종 반영을 판정합니다. 현재 17종의 실제 활성 여부는 `assets/fish-expansion/ready.js`, `assets/fish-expansion-023/ready.js`, `assets/special-creatures/ready.js` 각각을 확인하십시오.

## 대량 생산 정렬 규칙

1. 단독 이미지 존재 → 원본 해시·형태·지역·기존 ID 확인 → 바로 어종에 배정
2. 원화는 있지만 이미지 커팅 위험 → 원본 보류·재원화 또는 비파괴 투명 여백 해결
3. 겹치는 이미지·색 바꿈·이미 등록된 학명 → 신규 어종이 아닌 대체 원화 후보
4. 특수 실존 무척추동물과 가상 생물은 S 목록으로 분리하고 명시적 레어 연출 지정
5. 종별 PNG가 없는 시트/컨셉 포스터는 게임 LIVE에 합산하지 않음
6. 각 배치의 산출물은 **이미지+학명/이름+서식지/크기/희귀도+행동+도감+manifest+QA**를 하나로 검증

자동 검증: `qa-fish-fast-inventory.cjs`는 업로드 전 대기 상태와 업로드 후 17개 원본 전부가 활성화된 상태를 구분해 확인합니다.
