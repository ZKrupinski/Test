# 인간낚시 / HUMAN FISHING — 웹 알파 0.1

[▶ 게임 플레이 (GitHub Pages)](https://zkrupinski.github.io/Test/human-fishing/)

기존 프로젝트와 분리된 `human-fishing/` 독립 폴더입니다. 프레임워크/외부 CDN 없이 `index.html` 하나로 동작합니다.

## 현재 구현
- 물고기낚시: 움직이는 찌를 손가락/마우스로 드래그한 뒤 손을 떼면 가까운 물고기 자동 입질 및 포획 애니메이션
- 실시간 베지어 곡선 낚싯줄: 처짐과 장력에 따른 변형
- 물고기 240종, 서식지 12개 선택 가능, 등급에 따른 포획 진주 지급
- 인간낚시: 24종 인간 캐릭터 명단 기반 프로토타입, 찌로 포획
- 아쿠아리움: 잡은 물고기를 수조에 자유롭게 추가/회수, 최대 30마리, 장식 테마 3종, 실시간 유영
- 도감: 이름 및 서식지 필터, 발견/미발견, 보유 수량
- 성장: 촉수 파워, 찌 감각, 진주 보너스 각 5레벨
- 자동 저장: 브라우저 localStorage

## 조작 방법
1. `물고기낚시`에서 왼쪽 상단 스테이지명을 눌러 서식지를 변경합니다.
2. 수중 물고기 가까이 찌를 누르거나 빈 수면을 터치하여 드래그합니다.
3. 손을 떼면 가장 가까운 대상이 낚여 올라옵니다. 멀면 실패하며 다시 도전할 수 있습니다.
4. 포획 후 `아쿠아리움`에서 물고기를 추가하고 감상할 수 있습니다.
5. `성장`에서 진주로 낚시 능력을 강화합니다.

## 알파 한계 / 후속 제작
- 현재 물고기/문어/인간은 **임시로 그린 래스터 캐시 이미지**이며, 업로드된 레퍼런스 원화를 직접 적용한 버전은 아닙니다.
- 240종은 도감 데이터/이름/서식지/색상 시드가 들어가 있으나, 240개 전용 종별 스프라이트를 제작한 상태는 아닙니다.
- 아쿠아리움의 생태적 사육 적합성은 재현하지 않은 가상 전시입니다.
- 실제 인간/물고기 대립 AI, 희귀 연출, 수조 환경 편집, 사운드팩, 계정/클라우드 저장, 네트워크 기능은 후속 개발 범위입니다.
- 개인 데이터는 해당 브라우저에서만 유지되며 브라우저 저장 데이터 삭제 시 초기화됩니다.
- 모바일 가로 화면 우선이며, 세로 화면에서도 입력 좌표가 비율에 맞게 변환됩니다.

## 배포
저장소의 기존 `.github/workflows/pages.yml`에서 main 브랜치를 배포하도록 구성되어 있습니다. 사이트가 404를 표시한다면 GitHub Actions / Pages 활성화 또는 배포 완료 상태를 확인해야 합니다.
