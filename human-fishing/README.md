## Alpha 1.1 — 피버 문어 미끼 회수 애니메이션

- 피버 광역기에서 촉수 8개를 펼친 뒤 문어 미끼가 즉시 사라지지 않고 낚싯줄을 감는 동안 낚싯대 끝까지 올라옵니다.
- 12단계 비트맵 프레임과 별도 굽힘 캐시로 촉수 끝을 안쪽으로 말며 서서히 접습니다.
- 회수 진행도에 미끼 좌표, 촉수 프레임, 낚싯줄 장력, 릴 손잡이 회전이 함께 연동됩니다.
- 다중 포획 생물이 문어의 입으로 들어가는 기존 연출을 유지하고, 회수 완료 뒤 재투척합니다.
- 자동 테스트에서 프레임 단계 감소, 릴 방향 상승, 굽힘 프레임 생성 및 연출 종료를 검증합니다.

## Alpha 1.0 — 수면 정지 없는 포물선 입속 포획

- 물고기와 인간은 낚인 지점에서 수면에 멈추지 않고, 살짝 위로 솟는 연속 포물선을 따라 문어 입 안으로 곧바로 이동합니다.
- 문어는 접근하는 생물을 보고 입을 미리 크게 벌리고, 도착하면 입을 닫습니다.
- 포획 이후 생물이 다시 이동하는 중복 연출은 제거했습니다.

## Alpha 0.9 — 상단 피버 표시 정리

- OCTO FEVER 게이지를 약 25% 줄여 화면 왼쪽 상단으로 이동했습니다.
- 스테이지 및 지역명 표시는 숨기고 진주/수집 표시는 오른쪽 상단에 유지했습니다.

## Alpha 0.8 — 문어 입속 포획 연출 · 하단 UI 제거

- 게임 화면 하단의 **상황 안내/찌 놓기 버튼**, 별도 조작 설명 푸터를 제거했습니다. 낚시 조작은 화면 아무 곳에서나 가상 조이스틱으로 진행됩니다.
- 물고기 또는 인간 포획 시 별도 창을 띄우지 않고, **문어가 얼굴의 입을 크게 벌려 낚인 생물을 입안으로 흡입**합니다. 입은 12단계 비트맵 프레임으로 열리고 닫힙니다.
- 잡힌 개체가 포획 지점에서 문어 입까지 완전한 모습으로 곡선을 따라 이동하다가 **입에 도착할 때 통째로 작아져 사라지도록** 구현했습니다. 포획 연출이 끝나면 다음 낚싯대 투척이 자동 시작됩니다.
- **OCTO FEVER**는 미니 문어가 촉수 8개를 펼쳐 여러 대상을 포획한 다음, 잡힌 개체들이 **한 마리씩 순서대로 메인 문어 입으로 들어가는 연출**을 사용합니다. 모든 개체가 들어간 후 새 투척을 시작합니다.
- 물고기와 인간 엘리트 모두 흡입 연출을 공유합니다. 피버에 들어온 인간 엘리트도 매우 낮은 개별 성공률을 통과하면 다중 포획할 수 있고, 인간 보스는 광역 포획에서 제외됩니다.
- 진주 지급, 도감 등록, 아쿠아리움 배치, 희귀도 저항 및 저장 로직은 유지합니다.
- 자동 실행 테스트에서 하단 요소 삭제, 문어 입 프레임 생성/개방, 피버 다중 포획과 인간 연출, 입속 흡입 완료 후 재투척을 확인합니다.

## Alpha 0.7 — OCTO FEVER + 물고기 레벨·희귀도 저항

- 물고기 도감 240종에 각 서식지별 레벨(1~75)과 6등급(일반/고급/희귀/영웅/전설/신화)이 적용됩니다. 높은 등급과 레벨일수록 출현율이 낮고, 미끼에 걸리더라도 저항하다 탈출할 확률이 높습니다.
- 낚시에 걸린 뒤의 포획은 독립적인 확률 판정입니다. 실패하면 줄을 뿌리치는 연출이 재생되고 진주, 도감, 수조 보상은 지급되지 않습니다.
- 낚싯대·미끼·어망·조력자·문어의 구매, 장착, 단계별 업그레이드 효과가 희귀 개체 포획률을 높입니다. 신화 어종은 초급 장비로 매우 어렵습니다.
- 인간 엘리트의 출현 확률은 희귀 물고기보다 낮으며 포획 저항이 더 강합니다. 인간 보스 4종은 엘리트보다 더욱 희박하게 출현하며 포획률도 극히 낮게 설정되었습니다.
- 물고기 포획 6회부터 **OCTO FEVER** 발동 판정이 시작됩니다. 문어 종류/강화 수준에 따라 발동 확률이 증가하고 16회 누적 시 발동을 보장합니다. 상단이 아니라 좌측 피버 게이지에 표시됩니다.
- 피버가 준비되면 다음 낚시의 찌가 미니 문어 형태로 변신합니다. 가상 조이스틱을 이동시켜 손을 떼면 촉수 8개가 사방으로 펼쳐져 업그레이드 반경 안 물고기를 동시 포획합니다. 범위 안에서도 물고기마다 별도의 저항/포획 확률 판정이 이루어지며, **인간 보스는 범위 포획 대상이 아닙니다**.
- 장비 상점에 문어 전용 6종이 추가되어 총 30종입니다. 문어 종류별 색상·크기·피버 확률·공격 반경·포획 보정이 달라지며 각 모델을 10레벨까지 강화할 수 있습니다.
- 피버와 일반 포획/탈출 연출에는 화면 중앙 결과 팝업이 사용되지 않습니다. 기존 저장 키 humanFishingAlpha01을 유지합니다.

## Alpha 0.6 — 포획 팝업 제거 및 인게임 연출

- **포획 성공 시 중앙 창을 띄우지 않음.** 낚인 생물이 낚싯줄 끝에서 튀어 올라 사라지면서 작은 NEW/포획 이름/진주 보상 텍스트가 잠시 떠오릅니다.
- 포획 지점을 중심으로 원형 물보라·진주 입자가 퍼지고 일부는 상단 진주 계수기로 날아갑니다.
- 포획 연출이 진행되는 동안 별도의 클릭으로 닫아야 하는 창은 없으며 다음 찌 투척이 자동으로 시작됩니다.
- 기존 도감·아쿠아리움 등록, 진주 지급, 추가 포획 효과 및 저장을 유지합니다.
- 실패나 보조 알림은 화면 상단에 작게 표시하며 중앙 대형 박스는 사용하지 않습니다.

## Alpha 0.5 — 착수 직후 가상 조이스틱 조작

- 문어의 낚싯대 투척, 착수 물보라, 자연스러운 잠수 연출은 그대로 유지합니다.
- 공중에 있는 동안에는 터치 조작이 작동하지 않습니다.
- **찌가 물에 닿은 시점부터** 화면의 빈 곳을 포함해 캔버스 어느 곳이든 누르면 그 위치에 반투명 **가상 아날로그 조이스틱**이 표시됩니다.
- 침강 중 조이스틱을 누르면 **현재 깊이에서 침강 연출을 중단**합니다. 기본 깊이까지 내려갈 때까지 기다릴 필요가 없습니다.
- 조이스틱은 손가락을 움직이는 방향과 기울기만 전달합니다. **미끼의 현재 위치를 유지한 채 연속 이동**하므로 터치 지점으로 순간이동하지 않습니다.
- 조이스틱을 손에서 놓으면 사라지며, 실제로 움직인 경우에만 주변 생물 포획을 판정합니다. 탭만으로는 낚이지 않습니다.
- 모바일 터치와 PC 마우스 드래그 모두 같은 상대 이동 방식으로 처리합니다.
- GitHub Actions의 smoke 테스트는 착수 전 입력 제한, 착수 후 조기 입력, 조이스틱 표시·해제, 방향 이동, 순간이동 방지, 상점 조작을 검사합니다.

## Alpha 0.4 — 자연스러운 찌 투척·침강과 장비별 상점

- **투척 시퀀스**: 문어를 화면 중앙 가까이 재배치하고, 낚싯대가 휘둘러지며 낚싯줄이 풀리고, 찌가 수면에 착수한 뒤 서서히 수중 중앙(1280×720 기준 x=640)으로 내려갑니다. 착수 물보라·잠수 미세 기포가 재생됩니다.
- **미끼만 드래그**: 포인터가 미끼 주변에서 시작하지 않으면 미끼가 움직이지 않습니다. 투척·침강 중에는 입력을 무시하며 드래그 11px 이상 움직인 뒤 손을 떼야 포획 판정이 나옵니다. 단순 화면 터치나 미끼 탭은 이동/포획하지 않습니다.
- **장비 종류**: 낚싯대 6종, 미끼 6종, 어망 6종, 조력자 6종 = 24개 장비 모델. 장비별 구매·장착·개별 최대 레벨 10 강화 지원.
- **상점 정렬**: 낚싯대/미끼/어망/조력자 탭과 등급 낮은순, 가격 낮은순, 레벨 높은순, 이름순 정렬을 지원.
- **장착 효과**: 낚싯대 포획거리·릴 속도·색상, 미끼 희귀 출현·입질거리·색상, 어망 중복 포획·보상, 조력자 릴 속도·자동 진주·외형 및 인원 변경.
- 기존 localStorage 저장 키 humanFishingAlpha01을 유지하고 구버전 데이터에 장비 목록 필드만 추가해 이어서 플레이할 수 있습니다.

## 플레이 콘셉트

아기 문어가 **수면 위에서 낚싯대를 쥐고**, 벡터 곡선 낚싯줄을 아래로 드리워 물고기와 물속에서 헤엄치는 **엘리트·보스 인간**을 한 낚시터에서 함께 잡습니다.

- 찌를 터치/마우스로 드래그한 다음 목표 가까이 손을 놓으면 자동으로 포획합니다.
- 포획은 물고기와 인간 모두 **하나의 조작·낚시터·보상 시스템**을 공유합니다.
- 인간은 총 24종: 일반 인간 캐릭터도 ELITE, 마지막 4종은 BOSS 등급으로 표현됩니다.
- 일반 물고기는 12개 서식지 × 20종 = 240종 데이터가 적용되어 있습니다.
- 통합 생물 도감은 물고기 240종 + 인간 24종 = 총 264개 항목을 표시합니다.
- 아쿠아리움: 물고기 최대 30마리, 인간 최대 8명. 인간은 수중 거품 캡슐 안에서 전시합니다.
- 자동 저장: `localStorage`. 이전 알파의 포획 데이터·진주·성장 데이터를 유지합니다.

## 낚싯대 및 장비 상점

상단 **🛒 상점** 메뉴에서 진주를 사용해 각 아이템을 10단계까지 강화합니다.

| 장비 | 효과 |
| --- | --- |
| 낚싯대 | 잡을 수 있는 거리 +16px/레벨, 릴 감기 속도 +5%/레벨 |
| 미끼 | 희귀종·보스 출현 확률 및 입질 범위 증가 |
| 어망 | 중복 포획 확률 +8%p/레벨, 진주 보상 +4%/레벨 |
| 조력자 | 릴 감기 속도 +2%/레벨, 플레이 중 35초마다 진주 +5×레벨 |

낚싯대는 문어 촉수가 쥐고 있는 손잡이·릴·가이드 링과 함께 게임 화면에 표시됩니다. 낚싯줄은 반응형 곡선으로 구현되어 평소 처짐과 포획 순간 장력을 표현합니다.

별도로 기존 **✦ 성장** 강화(촉수 파워·찌 감각·진주 보너스)도 유지합니다.

## 알파 버전 주의

- 임시 게임 그래픽으로 구현했습니다. 원본 참고 이미지와 실제 어종별 스프라이트 240종은 아직 적용되지 않았습니다.
- 낚싯대는 현재 게임 화면 내 렌더링 아트로 그려집니다. 아트 전용 리소스로의 전환은 후속 작업입니다.
- 물고기와 인간의 장기 AI, 정교한 보스 패턴, 아쿠아리움의 실제 생태 조건, 계정 간 클라우드 세이브는 구현되지 않았습니다.
- 원본 이미지를 활용한 정식 외형·애니메이션 제작과 모바일 실기 QA는 아직 별도 작업이 필요합니다.
