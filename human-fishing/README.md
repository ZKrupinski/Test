# HUMAN FISHING / 인간낚시 — 웹 알파 0.3

**게임 실행:** https://zkrupinski.github.io/Test/human-fishing/

**소스:** https://github.com/ZKrupinski/Test/tree/main/human-fishing

기존 프로젝트와 분리된 `human-fishing/` 독립 웹 게임입니다. 정적 HTML/CSS/JavaScript로 외부 CDN 의존성 없이 실행합니다.

## 플레이 콘셉트

아기 문어가 **수면 위에서 낚싯대를 쥐고**, 벡터 곡선 낚싯줄을 아래로 드리워 물고기와 물속에서 헤엄치는 **엘리트·보스 인간**을 한 낚시터에서 함께 잡습니다.

- 찌를 터치/마우스로 드래그한 다음 목표 가까이 손을 놓으면 자동으로 포획합니다.
- 포획은 물고기와 인간 모두 **하나의 조작·낚시터·보상 시스템**을 공유합니다.
- 인간은 총 24종: 일반 인간 캐릭터도 ELITE, 마지막 4종은 BOSS 등급으로 표현됩니다.
- 일반 물고기는 12개 서식지 × 20종 = 240종 데이터가 적용되어 있습니다.
- 통합 생물 도감은 물고기 240종 + 인간 24종 = 총 264개 항목을 표시합니다.
- 아쿠아리움: 물고기 최대 30마리, 인간 최대 8명. 인간은 수중 거품 캡슐 안에서 전시합니다.
- 자동 저장: `localStorage`. 이전 알파의 포획 데이터·진주·성장 데이터를 유지합니다.

## 낚싯대 및 장비 상점

상단 **🛒 상점** 메뉴에서 진주를 사용해 각 아이템을 10단계까지 강화합니다.

| 장비 | 효과 |
| --- | --- |
| 낚싯대 | 잡을 수 있는 거리 +16px/레벨, 릴 감기 속도 +5%/레벨 |
| 미끼 | 희귀종·보스 출현 확률 및 입질 범위 증가 |
| 어망 | 중복 포획 확률 +8%p/레벨, 진주 보상 +4%/레벨 |
| 조력자 | 릴 감기 속도 +2%/레벨, 플레이 중 35초마다 진주 +5×레벨 |

낚싯대는 문어 촉수가 쥐고 있는 손잡이·릴·가이드 링과 함께 게임 화면에 표시됩니다. 낚싯줄은 반응형 곡선으로 구현되어 평소 처짐과 포획 순간 장력을 표현합니다.

별도로 기존 **✦ 성장** 강화(촉수 파워·찌 감각·진주 보너스)도 유지합니다.

## 알파 버전 주의

- 임시 게임 그래픽으로 구현했습니다. 원본 참고 이미지와 실제 어종별 스프라이트 240종은 아직 적용되지 않았습니다.
- 낚싯대는 현재 게임 화면 내 렌더링 아트로 그려집니다. 아트 전용 리소스로의 전환은 후속 작업입니다.
- 물고기와 인간의 장기 AI, 정교한 보스 패턴, 아쿠아리움의 실제 생태 조건, 계정 간 클라우드 세이브는 구현되지 않았습니다.
- 원본 이미지를 활용한 정식 외형·애니메이션 제작과 모바일 실기 QA는 아직 별도 작업이 필요합니다.
